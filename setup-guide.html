깃허브에서 직접 코딩해도 아래 설정은 어차피 직접 하셔야 해서 크게 달라지지 않아요. 막혔던 건 코드가 아니라 클라우드 작업 환경의 네트워크 차단(api.supabase.com, dapi.kakao.com)과 Supabase 인증 토큰이 없다는 점이에요.

아래 설정을 한 번만 해 두면(10분 정도), 3단계부터는 코드 작업이라 지금 방식으로 계속 진행할 수 있어요.

B. Claude가 Supabase까지 직접 하기

클라우드 환경 설정(세션 제목 표시줄의 환경 메뉴 → Edit)에서:

  • Network access의 Allowed domains에 api.supabase.com, *.supabase.co, dapi.kakao.com 추가
  • Supabase 개인 액세스 토큰을 SUPABASE_ACCESS_TOKEN 이름으로 등록(Network secrets 또는 환경변수)
  • 새 세션 열기
주의
이 토큰은 계정 전체 권한이라, 작업 후 Supabase에서 폐기하는 걸 권해요. 채팅에는 붙여넣지 마세요.

C. 내 컴퓨터에서 Claude Code 실행

Supabase 로그인과 카카오 지도 화면 확인이 모두 내 PC에서 바로 돼요. 화면을 같이 보면서 개발하기에는 이 방법이 제일 편해요.

처음 한 번 하는 설정

0 / 0 완료
1

Supabase 프로젝트 만들기

npx supabase login
npx supabase link --project-ref <프로젝트-ref>
npx supabase db push --include-seed

<프로젝트-ref>는 대시보드 주소 supabase.com/dashboard/project/여기에 있는 값이에요.

CLI 대신 대시보드로 하려면: SQL Editor에서 supabase/migrations/의 두 파일을 이름 순서대로(20261031…_init.sql → 20261101…_admin_save_restaurant.sql) 실행한 뒤 supabase/seed.sql을 실행하세요.
2

.env.local 만들기

프로젝트 폴더에 .env.local 파일을 만들고 아래 내용을 넣으세요. Supabase 값은 Project Settings → API에서 복사해요. 이 파일은 git에 올라가지 않아요.

NEXT_PUBLIC_SUPABASE_URL=https://<프로젝트-ref>.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<anon 또는 publishable 키>
NEXT_PUBLIC_KAKAO_MAP_APP_KEY=<카카오 JavaScript 키>
3

카카오 개발자 콘솔

도메인이 등록되어 있지 않으면 주소 검색에서 "SDK를 불러오지 못했어요" 안내가 나와요.

4

관리자 계정 만들기

누구나 관리자가 될 수 없도록 관리자 가입 화면은 따로 없어요. 계정을 만든 뒤 SQL로 역할을 바꿔요.

update public.profiles
set role = 'admin'
where id = (select id from auth.users where email = 'admin@example.com');

-- 확인
select u.email, p.role
from public.profiles p join auth.users u on u.id = p.id;

권한을 되돌릴 때는 role = 'owner'로 바꾸면 돼요.
